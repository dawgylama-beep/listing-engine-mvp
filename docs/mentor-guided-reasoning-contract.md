# Mentor-guided reasoning contract

Version 1.12.36 adds a deterministic reasoning discipline to Katherine’s Eye’s existing Cognitive Lifecycle Governor policy boundary. “Mentor-guided” names the contract; it is not a person, persona, second agent, model, provider, service, route, evaluator, or authority.

The contract requires this bounded cycle before a Governor decision is assembled:

`mission → evidence → causal diagnosis → generalized lesson → complete solution path → bounded action → verification`

The production integration is one internal assertion inside `selectNextCognitiveAction`. It consumes the already-authoritative cognitive state and already-derived legal candidates. It does not make a model or provider call, select a different authority, add a response field, change a serializer or schema, persist a lesson, promote memory, or create an alternate execution path.

## Application rules

- Reconstruct the current mission, project, thread role, checkpoint, finish line, and authority before choosing an action.
- Reconcile current observations with preserved history and checkpoint evidence before classifying facts as unavailable.
- Keep evidence, inference, conclusion, and authorization distinct.
- Classify observations at their actual domain and environment scope.
- Prefer the earliest causal boundary that explains all material observations.
- Audit the complete consumer and dependency closure of a confirmed defect class.
- Preserve the complete desired finish path while selecting only the smallest currently safe, authorized action.
- Continue independent authorized work when one branch is blocked.
- Skip repeated evidence or authorization work when the checkpoint is unchanged and the repetition would create no material state change.
- Stop only at an identity, safety, authority, or dependency boundary.

The fixture evaluator is deterministic, offline, non-persistent, and test-only. Its generalized lesson is an ephemeral rule derived from the current bounded evidence; it is never installed as memory and never establishes learning or cognitive improvement.

## Governance and claims

The contract does not alter the frozen V3 corpus, prompt, continuation policy, route, broker, schema, serializer, envelope, authority, execution records, evaluator, or result seal. The permanent V3 classification remains `KATHERINE_SYNTHETIC_EXECUTIVE_V3_BLIND_NOT_QUALIFIED_AFTER_V2_COGNITIVE_REMEDIATION`.

Passing these offline contract tests proves only that the specified deterministic rules and regressions behave as implemented. It does not prove qualification, learning, cognitive improvement, deployment, activation, or memory improvement.
